# Педагог көмекшісі

Мұғалімдерге арналған ЖИ портал (Node.js). Қазақ тілінде жұмыс істейді. ЖИ ретінде **Claude (API кілтімен)** немесе **Ollama (компьютерде, кілтсіз)** қолданылады. Деректер **SQLite** базасында, әр мұғалімнің өз тіркелгісінде сақталады.

| Бөлім | Не істейді |
|---|---|
| **Чат-бот** | Әдістеме, сынып басқару, ата-аналармен жұмыс туралы әңгіме. Тарих сақталады. |
| **AI ассистент** | 9 дайын құрал: идеялар, мәтін бейімдеу, аударма, кері байланыс, жауапты бағалау, ата-анаға хат, әдістемелік кеңес, іс-шара сценарийі, сабақты талдау. |
| **Материал дайындау** | 8 құжат түрі: ҚМЖ, тест, жұмыс парағы, БЖБ/ТЖБ, рубрика, презентация құрылымы, ойын/белсенді әдіс, мәтін және сұрақтар. |
| **Кітапхана** | Сақталған материалдар: іздеу, өңдеу, Word/PDF, JSON көшірме. |

## Іске қосу

Node.js 22.13+ қажет.

```bash
npm install
npm start
```

Сайт: http://localhost:3000 — алғаш ашқанда **Тіркелу** батырмасын басып тіркелгі жасаңыз.

## ЖИ-ді қосу: екі жол

### А) Ollama — кілтсіз, ақысыз (модель өз компьютеріңізде)

1. https://ollama.com сайтынан Ollama-ны орнатып, іске қосыңыз.
2. Модельді жүктеңіз (бір рет, бірнеше ГБ):

   ```bash
   ollama pull gemma3:12b
   ```

3. `npm start` — `.env` жоқ болса да, сервер автоматты түрде Ollama-ны таңдайды. «Баптаулар» бетінде күйін көресіз.

Модельді `.env` ішіндегі `OLLAMA_MODEL` арқылы ауыстыруға болады (мысалы, `qwen2.5:14b`; компьютер әлсіз болса — `gemma3:4b` немесе `qwen2.5:7b`). 12B модельге шамамен 16 ГБ жад ұсынылады. Кішірек модельдердің қазақ тілі сапасы айтарлықтай төмен болады, сондықтан нәтижені міндетті түрде тексеріңіз.

### Ә) Claude — сапасы жоғары, API кілті керек

`.env.example` файлын `.env` деп көшіріп, ішіне `ANTHROPIC_API_KEY=sk-ant-...` жазыңыз (https://console.anthropic.com). Кілтті сайттың «Баптаулар» бөлімінде де енгізуге болады (тек Ollama міндеттелмесе).

## Тіркелгілер мен база

- Деректер `data/app.db` (SQLite) файлында. Файлды көшіріп алсаңыз — сақтық көшірме дайын.
- Құпиясөз `scrypt` арқылы хэштеледі, сессия HttpOnly cookie-де.
- Мектепте қолданғанда `.env` ішінде `REGISTRATION_CODE=...` қойыңыз — тек коды бар мұғалімдер тіркеле алады. Интернетке HTTPS арқылы шығарсаңыз, `COOKIE_SECURE=1` қосыңыз.
- Бұрын браузерде (localStorage) сақталған материалдар мен чаттар алғашқы кіргенде тіркелгіге көшірілсін бе деп сұралады.

## Баптаулар (.env)

Толық тізім `.env.example` файлында: `PROVIDER`, `ANTHROPIC_API_KEY`, `MODEL`, `OLLAMA_MODEL`, `OLLAMA_URL`, `OLLAMA_NUM_CTX`, `REGISTRATION_CODE`, `ALLOW_REGISTRATION`, `DB_PATH`, `COOKIE_SECURE`, `PORT`, `APP_NAME`, `RATE_LIMIT`.

## Құрылым

- `server.js` — Express, `/api/ai` (SSE стрим), провайдер таңдау.
- `providers.js` — Claude және Ollama провайдерлері (бірдей интерфейс).
- `routes.js`, `db.js` — тіркелу/кіру, кітапхана мен чат API, SQLite.
- `prompts.js` — жүйелік нұсқаулар (ҚР мектеп контексті, әр құрал/құжат түрі үшін құрылым).
- `public/js/catalog.js` — форма өрістері мен сұрау үлгілері: жаңа құрал қосу үшін осы файлға жазба қосыңыз және `prompts.js`-те сол `id` үшін нұсқау жазыңыз.
